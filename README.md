# Projeto AudioVisual React

Aplicação web para exploração e reserva de equipamentos audiovisuais.

## 🚀 Funcionalidades
- **Catálogo & Detalhes:** Consulta de equipamentos, preços e disponibilidade.
- **Favoritos:** Gestão de itens favoritos via React Context.
- **Reservas:** Criação e cancelamento de reservas.

## 🛠️ Tecnologias
- React + Vite
- React Router DOM
- Tailwind CSS
- Lucide React

## ⚙️ Como Executar

```bash
npm install
npm run dev
